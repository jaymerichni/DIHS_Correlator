  - Unknown sample-size sweep: `1..20`

  - `MAX_SAMPLING_ITERATIONS = 5000`

  - Script runs with `MAX_DEPTH = 100` and computes DIHS at a common depth level per sampled run set.
  - This compact summary reports per-method performance aggregates and does not include an explicit depth column.
- **Archive status:** Compact release summary (intermediate per-scenario/model run files were removed during pre-release compaction).

### 4–6) Sensitivity and data-size analysis

The following compact summary files are generated by
`scripts/3_sensitivity_data_size.py`:

- `results/3_sensitivity_data_size/sensitivity_summary_by_case_compact.csv`
- `results/3_sensitivity_data_size/sensitivity_summary_by_class_compact.csv`

- **Primary input:**
  - `data/processed/caio_italy_benchmark/full_italian_data.csv`
- **Upstream provenance:**

    and `scripts/0_raw_data_preprocessing.ipynb`).
- **Model and transformation settings:**
  - Feature space: `Coupled`
  - Transform: `clr`
  - Models: `agglomerative`, `kmeans`, `gaussian`
  - Unknown sample-size sweep: `1, 2, 4, 5, 7, 10, 12, 15, 18, 20, 22, 25`
  - Dataset-size sweep: `25%`, `50%`, `75%`, `100%`
  - Positive/negative pseudo-unknown conditions.
- **Random seeds / stochastic control:**
  - `RANDOM_STATE = 12345`
  - `N_ITERATIONS = 100`
  - `MAX_DEPTH = 100`

#### `sensitivity_threshold_summary_compact.csv`
Per-model threshold summaries. Includes `integration_depth` and
`common_depth_level` columns.

#### `sensitivity_summary_by_case_compact.csv`
Per-model case summaries. Margins and true-positive fractions are aggregated
at each run's shared integration-depth selection.

#### `sensitivity_summary_by_class_compact.csv`
Per-model class summaries. Class-wise metrics are computed from pseudo-unknown
outputs evaluated using the same run-level integration-depth convention.

- **Archive status:** Compact release summaries.
